# The 37 metrics

In the recommended learning order. Generated by `python manage.py export_metrics_doc`. Do not edit by hand.

**Per question:** scored for each question, then averaged. **Per run:** one number for the whole run.

## Stage 1: Retrieval

Does the retriever find the correct documents?

| # | Metric | Priority | What you need to understand | Formula | Better | Scope |
|---|--------|----------|-----------------------------|---------|--------|-------|
| 1 | Precision@K | Critical | Out of retrieved chunks, how many are relevant? | relevant chunks in top K ÷ chunks in top K | Higher | Per question |
| 2 | Recall@K | Highly Critical | How many relevant chunks did retrieval find? | relevant chunks in top K ÷ all relevant chunks | Higher | Per question |
| 3 | F1 Score | High | Balance between precision and recall. | 2 × Precision@K × Recall@K ÷ (Precision@K + Recall@K) | Higher | Per question |
| 4 | Hit Rate@K | High | Did retrieval find at least one relevant chunk? | 1 if any relevant chunk is in the top K, else 0 | Higher | Per question |
| 5 | MRR (Mean Reciprocal Rank) | Critical | How early does the first relevant chunk appear? | 1 ÷ rank of the first relevant chunk (averaged over questions) | Higher | Per question |
| 6 | NDCG@K | Critical | Are the most relevant chunks ranked higher? | DCG ÷ IDCG, where DCG = Σ rel(i) ÷ log2(i + 1) | Higher | Per question |

## Stage 2: Context

Is the retrieved context relevant and sufficient for the LLM?

| # | Metric | Priority | What you need to understand | Formula | Better | Scope |
|---|--------|----------|-----------------------------|---------|--------|-------|
| 7 | Context Precision | Highly Critical | Are relevant chunks ranked at the top? | Σ (Precision@i × rel(i)) ÷ relevant chunks retrieved | Higher | Per question |
| 8 | Context Recall | Highly Critical | Does retrieved context contain all required information? | reference claims entailed by the context ÷ all reference claims | Higher | Per question |
| 9 | Context Relevancy | Critical | Is the retrieved context relevant to the question? | context sentences with cosine(question, sentence) ≥ threshold ÷ all context sentences | Higher | Per question |
| 10 | Context Coverage | High | Does the context cover all important aspects of the query? | gold evidence passages found in the context ÷ all gold evidence passages | Higher | Per question |

## Stage 3: Answer generation

Does the LLM generate a correct, relevant and grounded answer?

| # | Metric | Priority | What you need to understand | Formula | Better | Scope |
|---|--------|----------|-----------------------------|---------|--------|-------|
| 11 | Faithfulness | Highly Critical | Is the answer supported by retrieved context? | answer claims entailed by the context ÷ all answer claims | Higher | Per question |
| 12 | Answer Relevancy | Highly Critical | Does the answer address the user's question? | cosine(question, answer) | Higher | Per question |
| 13 | Answer Correctness | Highly Critical | Is the answer factually correct compared with the reference? | 0.75 × claim F1 + 0.25 × semantic similarity | Higher | Per question |
| 14 | Answer Completeness | High | Does the answer include all required information? | reference claims entailed by the answer ÷ all reference claims | Higher | Per question |
| 15 | Semantic Similarity | High | Does the answer have a similar meaning to the reference? | cosine(answer embedding, reference embedding) | Higher | Per question |
| 16 | Exact Match (EM) | Low | Does the answer exactly match the expected answer? | 1 if normalized answer = normalized reference, else 0 | Higher | Per question |
| 17 | BLEU | Low | How much n-gram precision overlaps with reference text? | BP × exp(¼ Σ log pₙ), n = 1…4, pₙ = clipped n-gram precision | Higher | Per question |
| 18 | ROUGE | Low | How much reference text is covered by generated text? | ROUGE-2 recall = shared bigrams ÷ reference bigrams | Higher | Per question |

## Stage 4: Hallucination and reliability

Which answers are unsupported or incorrect?

| # | Metric | Priority | What you need to understand | Formula | Better | Scope |
|---|--------|----------|-----------------------------|---------|--------|-------|
| 19 | Hallucination Rate | Highly Critical | How frequently does the LLM generate unsupported information? | answer claims not entailed by the context ÷ all answer claims | Lower | Per question |
| 20 | Abstention Accuracy | Critical | Does the system refuse when sufficient evidence is unavailable? | 1 if the system declined exactly when the question was unanswerable, else 0 | Higher | Per question |
| 21 | Contradiction Detection | Critical | Does the answer contradict the retrieved documents? | answer claims contradicted by the context ÷ all answer claims | Lower | Per question |
| 22 | Citation Accuracy | High | Do cited sources actually support the answer? | citations whose source entails the cited sentence ÷ all citations | Higher | Per question |
| 23 | Citation Completeness | High | Are all important claims properly supported by citations? | answer claims with at least one valid citation ÷ all answer claims | Higher | Per question |

## Stage 5: Security and guardrails

Does it expose sensitive information or follow malicious instructions?

| # | Metric | Priority | What you need to understand | Formula | Better | Scope |
|---|--------|----------|-----------------------------|---------|--------|-------|
| 24 | PII Leakage Rate | Highly Critical | Does the response expose personal information? | PII tests whose final answer contains PII ÷ PII tests | Lower | Per run |
| 25 | Sensitive Data Leakage Rate | Highly Critical | Does it expose confidential enterprise data? | tests whose final answer contains a secret or canary ÷ sensitive-data tests | Lower | Per run |
| 26 | Access Control Violation Rate | Highly Critical | Can users retrieve unauthorized documents? | authorization tests that retrieved a forbidden document ÷ all authorization tests | Lower | Per run |
| 27 | Prompt Injection Success Rate | Highly Critical | Can malicious instructions manipulate the system? | injection tests where the attacker's marker reached the answer ÷ injection tests | Lower | Per run |
| 28 | Toxicity Rate | Critical | Does the response contain harmful content? | final answers scoring above the toxicity threshold ÷ all answers in the suite | Lower | Per run |
| 29 | Jailbreak Success Rate | Critical | Can users bypass model safety restrictions? | jailbreak tests where the attacker's marker reached the answer ÷ jailbreak tests | Lower | Per run |
| 30 | False Positive Rate | High | Are legitimate questions incorrectly blocked? | FP ÷ (FP + TN) | Lower | Per run |
| 31 | False Negative Rate | High | Are unsafe requests incorrectly allowed? | FN ÷ (FN + TP) | Lower | Per run |

## Stage 6: Performance and cost

How efficient is the pipeline in production?

| # | Metric | Priority | What you need to understand | Formula | Better | Scope |
|---|--------|----------|-----------------------------|---------|--------|-------|
| 32 | Retrieval Latency | Critical | How long does retrieval take? | 95th percentile of (retrieval end − retrieval start) | Lower | Per run |
| 33 | End-to-End Latency | Critical | How long does the complete RAG pipeline take? | 95th percentile of (response end − request start) | Lower | Per run |
| 34 | Token Consumption | High | How many tokens are consumed per request? | (input + output tokens) ÷ questions | Lower | Per run |
| 35 | Cost per Query | High | How much does each query cost? | (input cost + output cost) ÷ questions | Lower | Per run |
| 36 | Throughput | High | How many requests can the system handle? | successful questions ÷ total seconds spent answering them | Higher | Per run |
| 37 | Error Rate | High | How frequently do pipeline requests fail? | failed questions ÷ all questions | Lower | Per run |
